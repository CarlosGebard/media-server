# Secrets and Variables

Runtime secrets come from Infisical via GitHub Actions OIDC.

## GitHub Environment Variables

- `INFISICAL_IDENTITY_ID`
- `INFISICAL_PROJECT_SLUG`
- `INFISICAL_ENV_SLUG`
- `INFISICAL_API_URL` for the external Infisical instance used by GitHub Actions

`INFISICAL_SECRET_PATH` is intentionally not a GitHub variable. The workflows
read the versioned paths `/global`, `/nextcloud`, and `/bitwarden`, so the
deployment can use service folders without duplicating
secrets. Do not rename those folders without changing the workflows.

## Infisical Secrets

Store these in `/global`:

- `PROD_SSH_PRIVATE_KEY`
- `PROD_HOST`
- `PROD_SSH_PORT` optional, defaults to `22`
- `PROD_SSH_KNOWN_HOSTS` optional
- `IMMICH_DB_PASSWORD` for Immich Postgres
- `COUCHDB_PASSWORD`
- `IMMICH_VERSION` optional, defaults to `v2`

Store these in `/nextcloud`:

- `NEXTCLOUD_ADMIN_PASSWORD`
- `NEXTCLOUD_DB_PASSWORD`
- `NEXTCLOUD_DB_ROOT_PASSWORD`

Store these in `/bitwarden`:

- `BITWARDEN_DB_PASSWORD`
- `BITWARDEN_INSTALLATION_KEY`
- `BITWARDEN_INSTALLATION_ID`
- `BITWARDEN_SMTP_PASSWORD` Resend API key used as the SMTP password
- `BITWARDEN_SMTP_FROM_EMAIL` optional, defaults to `vault@carlosjg.space`
- `BITWARDEN_SMTP_HOST` optional, defaults to `smtp.resend.com`
- `BITWARDEN_SMTP_PORT` optional, defaults to `465`
- `BITWARDEN_SMTP_SSL` optional, defaults to `true`
- `BITWARDEN_SMTP_USERNAME` optional, defaults to `resend`
- `BITWARDEN_DISABLE_USER_REGISTRATION` (`false` for the first deploy; change
  to `true` after the initial account exists)

`COUCHDB_USER` is fixed to `carlos`; `NEXTCLOUD_ADMIN_USER` is fixed to `admin`.
`IMMICH_DB_PASSWORD` is mapped to Immich's internal `DB_PASSWORD` environment
variable by Compose; do not create a second Infisical secret named
`DB_PASSWORD`.
`NEXTCLOUD_VERSION` is not secret and defaults to `34-apache`. Database name,
database user, trusted domain, proxy address, storage paths, upload limit, and
public URL are generated by the deployment workflow.

## Runtime File

Workflow materializes `/tmp/media-runtime.env` and Ansible copies it to:

```text
/srv/secrets/runtime/media.env
```

No production secret values should be committed.
